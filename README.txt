MI FINANZAS 15/30 — PRIMERA VERSIÓN

Esta es una aplicación web instalable (PWA), diseñada para Android.
Incluye:
- PIN de 4 a 8 dígitos (hash SHA-256 almacenado localmente).
- Registro de ingresos, gastos y ahorros.
- Separación por quincena 15 y 30.
- Resumen y consulta de movimientos por mes.
- Exportación CSV y copia de seguridad JSON.
- Caché para funcionamiento sin conexión después de la primera carga.

IMPORTANTE:
1. Los datos se guardan en el almacenamiento local del navegador/dispositivo.
2. No se sincronizan entre dispositivos.
3. Si borras los datos del navegador o desinstalas/limpias el sitio, puedes perder registros.
4. Descarga copias de seguridad periódicamente.
5. El PIN protege la interfaz, pero no equivale a cifrado completo de la base de datos.

CÓMO INSTALAR EN ANDROID:
1. Publica el contenido de esta carpeta en un alojamiento HTTPS (por ejemplo, GitHub Pages).
2. Abre la dirección HTTPS publicada en Chrome en tu Samsung.
3. Abre el menú ⋮ y elige "Instalar aplicación" o "Añadir a pantalla de inicio".
4. Confirma. Aparecerá el icono Mi Finanzas 15/30.

PARA PROBAR EN UNA COMPUTADORA:
Sirve esta carpeta desde un servidor local. Las PWA requieren HTTPS o localhost para instalarse y usar service worker.
